# rag-document-qa-system
A Python-based RAG system for document processing, semantic search, and AI-powered question answering using OpenAI embeddings, Qdrant, and n8n.  Copy Description
## Project Workflow

This project implements a Retrieval-Augmented Generation (RAG) system.

### Workflow

1. PDF Document Upload
2. Text Extraction
3. Text Chunking
4. Text Embedding Generation
5. Store Vectors in Qdrant
6. Retrieve Relevant Chunks
7. Generate AI Answers

### Technology Stack

- Python
- FastAPI
- n8n
- OpenAI Embeddings
- Qdrant Vector Database
